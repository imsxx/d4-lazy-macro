# Diablo Lazy Macro · 暗黑懒人宏

> 腱鞘炎一生之敌。*The lifelong enemy of your wrists.*

暗黑破坏神系列**专用**键鼠宏工具：一个程序覆盖**暗黑破坏神4 / 暗黑破坏神3 / 暗黑破坏神2：重制版**，开箱即用——内置方案预设，导入即用，不必为每一代游戏分别找工具、分别配一遍。支持连点、按住不放、单点、定时刷新，以及由屏幕取色驱动的 Buff 保持。作者在工具内配好规则并导出「分享码」，玩家粘贴导入即完成配置。

## 底线与功能分层

### 唯一底线：不做无人值守

**不做挂机与全自动打怪**：所有功能都必须有人在场——按键触发、手动开启、随时可停。这条底线不绕过、不例外。

### 为什么只有这一条

暗黑破坏神3 自发行以来，暴雪对按键宏长期保持宽容：封禁案例集中在无人值守的全自动挂机，按键宏（与雷蛇/罗技驱动宏属同一技术类别）并未因此被禁。而**暗黑破坏神4 缺少公开的长期验证**，因此对暗黑4采取保守策略，功能按风险分层投放。

### 功能风险分层

| 等级 | 功能 | 投放策略 |
| --- | --- | --- |
| 绿 | 连点 / 按住不放 / 单点、Buff 保持、方案切换、快速暂停 | 三款游戏均可用 |
| 黄 | 自动分解 / 重铸 / 升级 / 转换 / 拾取 / 赌博、按键队列、智能暂停 | 暗黑3 先行；**默认关闭**，界面明确标注未在其他游戏验证、风险自负 |
| 红 | 无人值守挂机、全自动打怪巡航 | 不做，也不接受相关贡献 |

### 技术手段约束（不随功能放宽而放宽）

- **不读游戏内存、不注入进程、不加载驱动**：只合成键鼠输入，屏幕识别仅使用公开的截图与取色
- **仅在目标游戏位于前台时发送**：切出游戏立即停止
- **Go 原生实现，不依赖 AHK 等脚本运行时**：与暴力外挂生态保持距离，同时换取干净的杀软表现与可维护性

## 使用

1. 双击桌面快捷方式「暗黑懒人宏」（或运行 `dist\diablolazymacro.exe`）：**主窗口打开，同时托盘常驻**。关闭窗口只是最小化到托盘，宏会继续运行；双击托盘图标可再次打开窗口
2. 主窗口是**左右双栏仪表盘**：
   - **右栏（全局）**：选游戏（暗黑4 / 暗黑3 / 暗黑2R，各自独立配置）、启动快捷键、宏启动方式、当前状态与目标进程，以及「保存并应用配置」「导入分享码」「复制分享码」「查看运行日志」。启动快捷键默认是**鼠标侧键 1**——三款暗黑游戏的默认键位都不占用鼠标额外按键（而暗黑3 的 `F1` 是「收藏」、`Shift` 是「强制站立」，都不能用），点按钮即可改，右键菜单能直接绑侧键/中键
   - **左栏（方案）**：4 套方案标签页，每页编辑配置名、切换快捷键和 6 个技能槽位（技能一~四 + 左键技能 + 右键技能）。每个槽位一行放下全部参数：**释放策略**（禁用 / 按住不放 / 连点 / 保持Buff）、**执行间隔**、**延迟**与**±随机**（仅连点：正数在周期内延后、负数推迟到周期末尾前）；快捷键按钮**点击后按任意键即可捕获**，右键菜单还能快速绑定鼠标左/中键与侧键。与当前策略无关的列会自动置灰，从界面层杜绝无效组合
   - **方案切换**：每个方案可指定一个切换键，游戏中按一下即切到该方案，不必回桌面开窗口
   - **按键模式**（每方案可独立选）：**并发按键**（默认）各技能各自计时、到点就按，互不影响；**循环按键**按槽位顺序一轮一轮按，一轮走完从头再来，与罗技/雷蛇驱动宏的顺序宏心智一致
3. **宏启动方式**决定触发语义：
   - **懒人模式**：按一下启动快捷键开，再按一下关
   - **仅按下时**：按住启动快捷键（推荐用鼠标侧键）时才生效，松开立即停止
   - 无论哪种方式，**只有目标游戏位于前台时才会发送按键**
4. **导入分享码**：复制一段分享码 →「从剪贴板导入分享码」→ 核对预览 → 确认应用
5. 作者侧：点「复制分享码」即可把配置发给别人（主窗口与托盘菜单都有）
6. 配置与日志在 `%APPDATA%\diablo-lazy-macro\`（窗口与托盘菜单都可打开数据目录）

## 日志与问题反馈

- 托盘右键 →「查看日志…」：窗口内可**复制全部**日志（含版本、系统、游戏与配置加载记录），直接贴给我们即可定位问题
- 日志同时落盘：`%APPDATA%\diablo-lazy-macro\logs\app.log`（超过 2MB 自动轮转）

## Phase 0 验证结果（2026-10-10）

在真实游戏（暗黑4）内全项通过：

- **键盘合成输入被游戏接受**：按住触发键与 F1 持续模式下，技能正常连发
- **鼠标合成输入被游戏接受**：`-spam "RMB"` 右键技能连点在游戏内生效
- **触发键轮询有效**：鼠标侧键、鼠标左右键、数字键均可作为按住触发（零全局钩子）
- **前台保护有效**：仅当目标进程位于前台时才发送（进程名匹配）
- **权限**：游戏进程非管理员，普通权限运行即可，不存在 UIPI 拦截

## 分享码

分享码在**工具内**生成与消费：作者导出即复制，玩家从剪贴板粘贴导入。格式为 `DLM1:` 前缀 + base64url 编码的紧凑 JSON（可带游戏标识）；导入时工具会渲染一份人类可读摘要供核对，绝不执行码中的任何代码。协议见 [docs/share-code.md](docs/share-code.md)。

## 开发

```powershell
.\build.cmd          # 双击可用：构建 dist\diablolazymacro.exe（发布版，无控制台）
go run .             # 开发运行（带控制台，便于看日志）
go run ./cmd/probe   # 运行 Phase 0 输入探针（回归验证用）
go test ./...        # 单元测试（协议、引擎、存档、日志、界面槽位）
go vet ./...         # 静态检查
```

Windows 资源（应用图标 + Common Controls v6 清单 + 版本信息）由 `winres.json` 生成，产物已入库；改动后重新生成：

```powershell
go run ./tools/mkico -in 源图.png -out assets/icon.ico -png assets/icon.png   # 图标：去水印、圆角透明、多尺寸 ICO
go run github.com/tc-hib/go-winres@latest make --in winres.json --out rsrc --arch amd64,arm64
```

探针用法与游戏内测试清单见 [docs/probe-checklist.md](docs/probe-checklist.md)。

## 项目结构

```
main.go                     # 执行器入口：托盘、热键、方案切换键、分享码导入/导出、多游戏切换、Buff 守卫接线
window.go                   # 主窗口：左右双栏仪表盘（方案 × 技能槽位、策略编辑、按键捕获）
keyitems.go                 # 键位候选项与中文键名（界面用）
logwindow.go                # 日志窗口（查看/复制上报）
slots_test.go               # 界面槽位与配置规则互转的回归测试
cmd/probe/main.go           # Phase 0 输入探针（回归验证用）
internal/win32/             # Win32 封装：SendInput 键鼠合成、GetAsyncKeyState 轮询、前台窗口检测、屏幕取色（pixel.go）
internal/keys/              # 协议键名白名单与虚拟键码互转
internal/games/             # 游戏表与（规划中的）游戏适配层：槽位布局、默认进程、屏幕识别
internal/config/            # 分享码解析、编码、校验与冲突提示（Fail Fast）
internal/engine/            # 规则引擎：tap/seq/once/hold 状态机、卡键防护、Buff 检测钩子（纯逻辑，可测试）
internal/store/             # 每游戏配置与工具设置的持久化
internal/logx/              # 日志器：内存环形缓冲 + 文件落盘 + 轮转
assets/icon.png|icon.ico    # 应用图标（源图 + 多尺寸 ICO）
tools/mkico/                # 图标工具：去水印、圆角透明、生成多尺寸 ICO
winres.json                 # Windows 资源定义（图标/清单/版本信息），生成 rsrc_windows_*.syso
docs/                       # 协议、测试与进度文档
```
