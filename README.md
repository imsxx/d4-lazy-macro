# D4 Lazy Macro · 暗黑4懒人宏

> 腱鞘炎一生之敌。*The lifelong enemy of your wrists.*

暗黑4键鼠辅助宏：只做**技能释放类**的按键自动化——连发、按住施法、定时刷新、按键序列。配置在网站上生成一段「分享码」，粘贴进工具即完成配置。

## 三条红线（什么是我们不做的）

- **不读游戏内存、不注入进程、不加载驱动**：只合成键鼠输入，与雷蛇/罗技驱动宏属于同一技术类别
- **一切动作由玩家按键/按住触发**：没有无人值守循环，人始终在环
- **不做自动打怪巡航、挂机、自动拾取/分解/做装**：那是 bot 领域，本项目不做，也不接受相关贡献

## 能力规划

| 阶段 | 内容 |
| --- | --- |
| Phase 0（已完成） | 输入探针：合成键鼠输入在游戏内生效、可配置触发键按住识别、前台窗口保护（2026-10-10 实测通过） |
| Phase 1（当前） | 执行器 MVP：托盘常驻 + 全局热键 + 剪贴板导入分享码 + 应用前预览 + 多方案切换 |
| Phase 2 | 与网站联动：网页配置器、分享码协议、流派预设页 |

## Phase 0 验证结果（2026-10-10）

在真实游戏内实测通过：

- **键盘合成输入被游戏接受**：按住触发键与 F1 持续模式下，技能栏 1 号位技能正常连发
- **触发键轮询有效**：鼠标侧键按住识别正常
- **前台保护有效**：仅当 `Diablo IV.exe` 位于前台时才发送（进程名匹配）
- **权限**：游戏进程非管理员，普通权限运行即可，不存在 UIPI 拦截
- 待验证：鼠标点击连发（`-spam "RMB"`）在游戏内的落地

## 分享码

配置在网站上生成一段可读的分享码，粘贴进工具即完成配置。分享码带版本号，工具只接受白名单字段与合法区间，不合法直接拒绝（Fail Fast），绝不执行码中的任何代码。

协议草案见 [docs/share-code.md](docs/share-code.md)。

## 开发
