# Phase 0 探针 · 游戏内测试清单

目的：验证「合成按键在暗黑4 内确实生效」「鼠标侧键按住可被轮询识别」「前台窗口保护有效」，并采集本机真实的窗口信息（标题/类名/进程名/权限级别）。

## 运行

```powershell
cd d:\GitHub\d4-lazy-macro
go run .
```

先**普通权限**运行——这就是将来用户的真实运行方式；探针会自行检测并在必要时警告权限问题，不需要盲试管理员。

## 测试项（约 5 分钟）

1. **窗口信息采集**：切到游戏，控制台应出现一行 `[窗口] 前台：... | 类名：... | 进程：Diablo IV.exe (PID ...) | 进程管理员：...`。
   把这一行原文反馈回来（用于归档真实类名，不硬编码猜测值）。
   - 若 `进程` 不是 `Diablo IV.exe`，用真实进程名重跑：`go run . -process "实际进程名.exe"`
2. **按住连发**：确保技能栏 1 号位有技能（或先用 `-spam` 换成你有技能的键）。在游戏里按住鼠标侧键（后退键），控制台出现 `[发送#n|按住]`，游戏内技能 1 开始连发；松开立即停止。
3. **启停开关**：按 F1 → 控制台 `[切换] 持续连发 = true`，技能 1 以 500ms 间隔自动释放；再按 F1 停止。
4. **前台保护**：切出游戏（记事本/浏览器），发送计数必须停止；切回游戏恢复。
5. **四键连发（可选）**：`go run . -spam "1,2,3,4"`，确认四个技能槽依次释放。

## 失败排查顺序

- **完全无反应**：先看控制台是否有 `[警告] 目标进程以管理员运行…`；有则用「以管理员身份运行」的终端重跑对比。
- **侧键按住无 `[发送..|按住]`**：检查鼠标驱动/厂商软件是否把侧键重绑成了键盘按键或其他功能——重绑后系统不再更新 XBUTTON 状态，轮询会失效。确认后反馈，升级为 Raw Input 方案（事件驱动，仍然零钩子）。
- **F1 被其他软件占用**：`go run . -toggle 0xNN` 换键（0xNN 为虚拟键码十六进制）。
- **游戏内聊天框打开时不要触发**：按键会打进聊天框。

## 反馈内容

窗口信息行原文 + 测试项 1–5 各自的结果 + 是否出现管理员权限警告。
