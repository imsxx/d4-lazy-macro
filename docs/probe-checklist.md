# Phase 0 探针 · 测试清单

目的：验证「合成输入在暗黑4 内确实生效」「触发键按住可被轮询识别」「前台窗口保护有效」，并采集本机真实的窗口信息（标题/类名/进程名/权限级别）。

## 基本用法

```powershell
cd d:\GitHub\d4-lazy-macro
go run .
```

默认：触发键 = 鼠标侧键 X1/X2；连发 = 键盘 `1`；启停键 = F1；间隔 250ms。

常用变体：

```powershell
# 把 1/2/3/4、鼠标左右键也作为触发键（配合技能键位测试）
go run . -hold "X1,X2,LMB,RMB,1,2,3,4" -spam "4"   # 连发键选 4，避免与触发键重叠

# 连发鼠标右键（右键技能连点）
go run . -spam "RMB"

# 四键循环连发
go run . -spam "1,2,3,4"

# 只测启停键（不需要按住触发）
go run . -hold ""
```

先**普通权限**运行——这就是将来用户的真实运行方式；探针会自行检测并在必要时警告权限问题。

## 测试项（约 5 分钟）

1. **触发键识别（不必进游戏）**：在任何窗口按下 `-hold` 列出的键，控制台应打印 `[触发] X 按住` / `[触发] X 松开`。
   **只有 `-hold` 列出的键会有输出，其余按键不会有任何反应——这是设计，不是故障。**
   - 侧键没有任何输出：检查鼠标驱动/厂商软件是否把侧键重绑成了别的东西（重绑后系统不再更新 XBUTTON 状态）。
2. **窗口信息采集**：切到游戏，控制台应出现一行 `[窗口] 前台：... | 类名：... | 进程：Diablo IV.exe (PID ...) | 进程管理员：...`。把这一行原文反馈回来。
   - 若 `进程` 不是 `Diablo IV.exe`，用真实进程名重跑：`go run . -process "实际进程名.exe"`
3. **键盘连发（关键项）**：确保技能栏 1 号位有技能。在游戏里按住触发键，控制台出现 `[发送#n|按住] 1`，游戏内技能 1 应持续释放；松开立即停止。
   **反馈时请明确说：游戏里有没有真的施放。**
4. **鼠标连发**：`go run . -spam "RMB"`，按住触发键，游戏内右键技能应连点释放。
5. **启停开关**：按 F1 → `[切换] 持续连发 = true`，技能以 500ms 间隔自动释放；再按 F1 停止。
6. **前台保护**：切出游戏（记事本/浏览器），发送计数必须停止；切回游戏恢复。

## 失败排查顺序

- **游戏内无反应、但控制台有 `[发送..]`**：说明 OS 层注入成功、游戏层未接受。先看是否有 `[警告] 目标进程以管理员运行…`，有则用管理员终端重跑对比；没有则把现象反馈回来，下一版换 scancode 方式注入验证。
- **控制台完全无输出**：确认按的键在 `-hold` 列表里；确认触发键本身没被鼠标/键盘驱动重绑。
- **F1 被其他软件占用**：`go run . -toggle 0xNN` 换键（0xNN 为虚拟键码十六进制）。
- **不要把同一个键同时放进 `-hold` 和 `-spam`**（会自我触发叠加，启动时会打印警告）。
- **游戏内聊天框打开时不要触发**：按键会打进聊天框。

## 反馈内容

窗口信息行原文 + 各测试项结果（尤其第 3、4 项游戏内是否真的释放）+ 是否出现管理员权限警告。
