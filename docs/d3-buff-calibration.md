# 暗黑3 Buff 守卫 · 实机标定记录

> 标定日期：2026-10-13　标定人：开发者 + AI 助手
> 目的：验证 `internal/games/d3.go` 的 Buff 守卫坐标与阈值（此前只有 1:1 复刻的公式，从未在真实游戏内实测）

## 结论

**`d3.go` 的实现无需修改，全部参数经实测确认。**

| 待验证项 | 公式值 | 实测结果 | 结论 |
| --- | --- | --- | --- |
| 采样点 Y（技能一） | 945 | 945 恰在图标顶部（950）上方 5px，无 Buff 时为黑 | ✅ 正确 |
| 采样点 X（技能一） | 603 | 按下 Buff 技能后该点由黑变亮 | ✅ 正确 |
| 阈值 `G >= 95` | 95 | 无 Buff = 11，有 Buff = 164~233 | ✅ 正确，区分度极大 |
| y 基准 = 客户区高度 | — | 用客户区高度（1025）算得 945 命中；用窗口高度（1064）算得 981 会落到图标装饰上 | ✅ 客户区高度 |
| x 基准 = 客户区宽度 + 高度缩放 | — | 与公式一致，无累积误差 | ✅ 正确 |

> 注意：客户区高度 1025 ≠ 参考高度 1440，因此坐标是等比缩放的（`scale = 1025/1440 ≈ 0.712`）。

## 方法

探针 `cmd/screenprobe` 一条命令完成：临时接管焦点 → 按 `1,2,3,4` → 立刻还原焦点 → 连拍并逐张报告采样点。

```
go run ./cmd/screenprobe -process "Diablo III64.exe" -activate \
  -press "1,2,3,4" -settle 600 -burst 8 -interval 500 \
  -px "603,945;667,945;729,945;793,945;859,945;921,945" \
  -out dist/d3-buff.png
```

## 原始数据

技能一（`603,945`）采样点的绿色分量随时间变化：

| 时刻 | RGB | G | 判定 |
| --- | --- | --- | --- |
| 按键前 | (11, 11, 11) | 11 | 未生效 |
| +0.6s | (58, 164, 37) | 164 | **生效** |
| +1.1s | (81, 173, 39) | 173 | 生效 |
| +1.6s | (100, 180, 42) | 180 | 生效 |
| +2.1s | (123, 189, 44) | 189 | 生效 |
| +2.6s | (144, 197, 47) | 197 | 生效 |
| +3.1s | (166, 206, 50) | 206 | 生效 |
| +3.6s | (190, 216, 52) | 216 | 生效 |
| +4.1s | (211, 224, 55) | 224 | 生效 |
| +4.6s | (234, 233, 58) | 233 | 生效 |

其余 5 个槽位（`667/729/793/859/921, 945`）全程保持 `RGB(13,14,14)` 无变化 —— 与"这 4 个键当前不是 Buff 技能"的说明一致。

**颜色从绿色渐变到黄色**，说明该处是 Buff 持续时间指示（绿→黄→红式的进度着色），而判据只看绿通道幅度，因此对渐变不敏感。

## 未验证项

以下项目本次**未能验证**，需要后续补测：

1. **槽位 2~6 的 X 坐标** —— 这些槽位当前都不是 Buff 技能，按 1234 后无变化，无法验证。
   公式对 6 个槽位用的是同一套换算（仅基准 X 不同），且槽位 1 完全吻合，因此**推定**其余槽位同样正确；若日后把 Buff 技能换到其他槽位，可用上面的命令复测。
2. **横坐标在 21:9 等其它宽高比下的表现** —— 本次只在 16:9（1817×1025）验证。
3. **Buff 消失瞬间的回落行为** —— 需要等 Buff 自然到期（本次连拍窗口只有 4.6 秒，未覆盖到期）。
4. **游戏以「全屏独占」模式运行时的表现** —— 该模式下无法抓取画面，需玩家使用窗口化/无边框窗口化。

## 复现与再标定

1. 启动暗黑3（窗口化），进入城内；
2. 用 `cmd/screenprobe` 定位窗口并确认能抓到画面：

   ```
   go run ./cmd/screenprobe -process "Diablo III64.exe" -out dist/d3-city.png
   ```

3. 按上文的命令自动按键并连拍；
4. 若换了显示器分辨率或游戏显示模式，重新执行第 2、3 步，把新数值与本表比对。
