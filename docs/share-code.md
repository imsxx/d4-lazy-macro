# 分享码协议 v1

> 状态：**草案（待评审）**。这是「网站配置器」与「桌面执行器」之间**唯一的交换格式**：网站在浏览器内生成，工具在本地解析并应用。任何一方放宽校验都属于缺陷。

## 形式

```
D4LM1:{"v":1,"tg":"F1","p":[{"r":[{"tg":"t","a":"tap:4","i":250}]}]}
```

- 前缀 `D4LM1:` 用于识别与版本声明；解析前先去除前缀，剥离所有空白字符后再做 JSON 解析
- 正文 `v` 字段必须与前缀版本一致
- 正文是紧凑 JSON，**不含任何可执行内容**；工具只读取白名单字段，绝不 eval
- 典型长度 100–250 字符，可直接贴进文章、视频简介与聊天窗口

## 设计取舍

- **选纯 JSON 而不是压缩 Base64**：可读、可审查（用户能看懂码里是什么）、无压缩依赖、出错可定位；典型码长与压缩后相差不大，而「透明」正是本项目的信任基础
- **版本号写进前缀**：旧工具遇到 `D4LM2:` 直接拒绝并提示升级，而不是尝试解析
- **无服务端**：码完全自包含，不需要账号、不联网即可导入

## 字段

### 顶层

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `v` | 是 | 协议版本，当前恒为 `1` |
| `n` | 否 | 配置名，≤ 24 字符 |
| `a` | 否 | 作者署名，≤ 24 字符 |
| `tg` | 否 | 全局启停键，默认 `F1` |
| `p` | 是 | 方案数组，1–4 个 |

### 方案 `p[]`

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `n` | 否 | 方案名，≤ 24 字符 |
| `r` | 是 | 规则数组，1–8 条 |

### 规则 `r[]`

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `tg` | 是 | 触发方式：`t` = 宏开启期间持续；`h:<键>` = 按住该键期间 |
| `a` | 是 | 动作：`tap:<键>` 单发；`seq:<键1>,<键2>…` 按顺序循环（≤ 6 键） |
| `i` | 是 | 间隔毫秒，范围 20–600000 |

## 键名

- 鼠标：`LMB` `RMB` `MMB` `X1` `X2`
- 键盘：`0-9`、`A-Z`、`F1-F12`、`TAB` `ESC` `SPACE` `CAPSLOCK`、`0xNN`（虚拟键码十六进制）

## 运行时语义（工具行为，不可由分享码配置）

- **总开关**：`tg` 键（默认 F1）是主控。关闭时任何规则都不触发；开启后 `t` 规则持续运行，`h` 规则在按住时触发
- **前台保护**：仅当目标进程（`Diablo IV.exe`）位于前台时发送；这是硬约束，防止按键散落到其它程序
- **同键去重**：同一键同时作为触发与动作会形成自我叠加，工具启动时警告
- **方案切换**：默认启用第一个方案，其余方案经托盘菜单切换（热键切换属后续版本）

## 示例

```
D4LM1:{"v":1,"n":"光矛法师-速刷","a":"某BD作者","tg":"F1","p":[{"n":"速刷","r":[{"tg":"t","a":"tap:4","i":250},{"tg":"h:X1","a":"seq:2,3","i":200},{"tg":"t","a":"tap:3","i":30000}]}]}
```

读法：F1 开启宏后，每 250ms 按一次技能 4；按住鼠标侧键 1 时循环按 2、3（间隔 200ms）；每 30 秒按一次技能 3（buff 刷新）。

## 校验规则（Fail Fast）

工具解析时必须逐项校验；任何一条不满足即**整段拒绝**、给出明确错误，禁止部分应用、跳过非法项或静默降级：

1. 前缀与 `v` 一致，且 `v == 1`
2. 未知字段一律拒绝（按白名单解析）
3. 整码 ≤ 2048 字符
4. `n` / `a` ≤ 24 字符；方案数 1–4；每方案规则数 1–8
5. `tg` 只接受 `t` 或 `h:<合法键名>`；`a` 只接受 `tap:<合法键名>` 或 `seq:` 后每个键名合法且 ≤ 6 个
6. `i` 为整数且在 [20, 600000]
7. 键名必须在白名单内

## 版本演进

- 语义或字段变化 → 升版本（`D4LM2:`）；旧版工具遇到未知版本必须拒绝并提示升级
- 工具声明支持的版本集合（v1 工具：`{1}`）；网站生成前必须校验，保证只产出工具能消费的版本

## 实现约定

- 工具（Go）：`json.Decoder` + `DisallowUnknownFields`，解析到强类型结构体，校验失败即返回错误
- 网站（浏览器）：同一份规则表实现生成态校验；生成前自动校验，不合法不允许导出
- 键名 → 虚拟键码映射表以工具仓库实现为准；网站侧维护等价表，并用测试锁定两表一致
